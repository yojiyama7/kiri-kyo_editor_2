# 同格の矢印のブラウザー確認

通常利用オリジンの保存内容は編集せず、検証用の2組目に

- [ ] 初期例のSから `r` を開始でき、Vの相手でEnterは案内を表示してARROWモードを維持する。
- [ ] 相手選択中に基礎下線へ入り、内部の空スロットへ接続できる。
- [ ] 接続済みの空側で `r` はNORMALのまま。`Shift+r` で削除でき、Undo / `Ctrl+r` で復元・再削除できる。
- [ ] n / S と O / nC の2組を作り、S側からnC側へ付け替えると双方の旧接続が1本に置換される。Escでは2本を保持する。
- [ ] 双方の接続置換は1回のUndoで元の2本に戻り、Ctrl+rで1本に戻る。
- [ ] EpsilonとThetaの個別選択から非連続下線を作り、ncを入力。その最後のregionからAlphaへ同格を引ける。
- [ ] 通常幅では非連続下線の最後の表示region中央に接続し、横線中央の下に「同格」を表示する。
- [ ] `+` 標識から同格を開始でき、`+` 標識を相手側にも選べる。保存・再読み込み後も接続と `+` 標識を維持する。
- [ ] 390px幅では横線が2行に折り返し、継続点が同色。ラベルは最後の行だけに表示される。開始側が後ろのregionでも同じ規則になる。
- [ ] 幅変更前後の論理配置JSONは完全に一致する。
- [ ] SVGで同格にpath（矢じり）がないこと、Y=1の横線41px・Y=2の79px、ラベルのベースラインが横線+18px、14px・縁取りなしを確認する。
- [ ] Zetaのadから同格接続済みのAlphaへ従来の矢印を追加できる。同格と別の横線として配置され、従来の矢印には矢じりが1つある。
- [ ] Alphaの標識削除では同格と従来の入射矢印を保持する。空側からのrは開始しない。nを戻すと元の接続を維持する。
- [ ] 再読込後の2組目の保存文書が再読込前と完全一致する。
- [ ] 通常幅・390px幅のスクリーンショットで確認し、一時的な表示幅指定を解除する。

両端の重複参加、未知の種類、空同士、T / D、連鎖削除、混合衝突、同位置接続、
履歴とversion 8読み込み、非連続regionと折り返しを検証する。
