# D分割のブラウザ確認

- [ ] 単語で `d` を押すと左右2枠を生成し、左へカーソルが移る。横線・縦線の疑似要素はどちらも `content: none`。
- [ ] 左右上で再度 `d` を押しても再分割しない。`ad` の標識入力で意図しない分割を生成しない。
- [ ] 左へ `ad`、右へ `o2` を入力し、`l` で右へ移動できる。
- [ ] `X` で解除すると左の標識を親に戻す。`u` / `Ctrl+r` で解除をUndo / Redoできる。
- [ ] 26単語を含む連続した複合下線をD分割できる。行をまたぐ元の下線・接続点を残し、左右枠は最後の表示区間だけに置く。中央の縦線は描かれない。
- [ ] 複数単語の連続下線で任意の単語位置にカーソルを置いて `d` を押すと、その単語の直後（末尾では直前）で左右非対称に分割される。
- [ ] 非対称D分割の左右の標識とformが各領域の中央に揃い、再読み込み・幅変更後も論理範囲は維持され、表示幅は左右それぞれの必要幅を満たす。
- [ ] 幅600pxへ変更しても論理範囲は変化せず、左右枠は1組だけ。Sと副詞的目的格の標識を表示できる。
- [ ] 再読み込み後もDの種類、左右のIDと標識、文書全体を保持する。
- [ ] ブラウザのコンソールエラーなし。
- [ ] 確認用の組を削除し、元の組の構造・標識・矢印・英文・訳文が一致することを確認。確認用の組の削除は通常のUndo対象。

対象制約、左右の選択・下線作成、非対称比率、基礎/複合下線の上移動、混在したT/Dの連鎖削除、矢印の引き継ぎ、保存検証は `dEditing.test.mjs` で検証。
