# 角括弧・丸括弧・山括弧のブラウザー確認（通常は実行しない）

ブラウザー起動を伴うため、「全てのテストを実行」または「時間のかかるテストを実行」と明示された場合のみ実施する。

- [ ] `<` / `>` はShift付きでもNORMALのregion左／右、BORDERの境目に独立して挿入できる。NORMALでは元の選択位置を維持する。
- [ ] `<` はクリック・左右移動で選択でき、記号全体がハイライトされる。選択だけではNORMALを維持し、標識の入力・削除、T/D・活用編集で変更されない。`>` は移動・選択で飛ばす。
- [ ] 範囲選択・個別選択に `<` を含めても、下線作成時は `<` を除いたスロットだけが構成要素になる。`<` だけを選択してEnterを押しても下線・履歴を作らずNORMALに戻る。`<` の選択表示・矢印操作は引き続き使える。
- [ ] `<` で `r` を押すと修飾矢印モードに入り、確定・取消でNORMALへ戻る。別の修飾矢印も `<` へ接続でき、同格は接続できない。`R` は出ている矢印だけを削除する。
- [ ] 山括弧は幅10pxで表示行の高さに追従し、矢印は `<` の下端に接続する。入出力の併存、`>` のみの行への折り返し、幅変更でも接続が保たれる。
- [ ] 標識操作後・再読込後も `<` の矢印が残る。BORDERで `<` を削除すると関連する矢印・下線・分割も削除され、Undo/Redoで選択位置とともに復元できる。

- [ ] `(` / `)` はShift付きでもNORMALのregion左／右、BORDERの境目に1文字ずつ挿入され、自動ペア補完されない。`(` は `<` と同じ仮想選択に対応し、`)` は通常の移動・選択で飛ばす。
- [ ] `(` で上記の `<` と同じ選択・編集制限・下線からの除外・矢印操作を確認する。古いスロットなしの `(` も再読込後に選択でき、矢印を作成できる。
- [ ] 丸括弧は幅10pxの曲線で、スロット用の余白を持たず、表示行の高さに追従する。矢印は `(` の下端に接続する。入出力の併存、丸括弧のみの行への折り返し、角括弧との混在、削除・Undo/Redo・再読込でも表示を維持する。

- [ ] BORDER で `[` / `]` を文頭・文中・文末・空の文書へ個別に挿入でき、右境目に留まる。長押しで連続挿入されない。
- [ ] normal の左右移動・クリックで `[` の専用スロットへ移動し、標識を入力できる。`]` にはスロットがなく、左右移動で飛ばす。
- [ ] `[` のスロットで T/D は作成されない。通常のトークンとともに選択して作る下線は複合下線になり、退出・再読込でも基礎下線にならない。
- [ ] 括弧の高さが表示行の上端から y=0 の下端までに収まる。長い単語・疑似トークンの折り返しで行高が増えても追従し、y=1 以降へ伸びない。
- [ ] `[` の標識・選択枠・矢印の接続位置が縦棒の右側にあり、上下の短い横棒と重ならない。長い標識を入力・削除しても余白が累積しない。
- [ ] 複数段の下線・矢印を作成しても y=0 の括弧と重ならない。下線途中への挿入はその位置を飛ばし、T/D分割元を不連続にする場合は挿入が拒否される。
- [ ] 狭い幅で `]` だけの表示行ができても、行をまたぐ矢印が描画される。幅変更後も論理位置とスロットIDは維持される。
- [ ] BORDER の Backspace / Delete は直前 / 直後の括弧だけを削除する。`[` の関連構造も削除され、Undo/Redoで一括復元できる。
- [ ] 閉じ括弧のみの文書は normal で未選択になる。文頭の `]`、末尾の `]`、連続する `]` の近くで境目から復帰してもカーソルが動けなくならない。
- [ ] 再読込で括弧と専用スロットが戻る。英文入力には実トークンのみが現れ、無変更なら括弧を維持し、英文変更時は案内どおりリセットされる。
- [ ] normal の `[` / `]` で現在の論理regionの左右へ挿入でき、元のスロット・region内の位置に留まる。非連続下線の別regionや表示上の折り返し位置は挿入先に影響しない。
- [ ] 対象方向の端が `[` 専用スロット、またはT/Dでトークンの途中になっている場合は理由が表示され、挿入・カーソル移動は起きない。反対側が有効なら、その側への挿入はできる。
- [ ] normal で `[`、`]` を続けて追加し、Undo/Redoでそれぞれ1操作として復元できる。入力中の標識は括弧挿入より前に確定する。
