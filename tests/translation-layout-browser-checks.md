# 訳文の文字配置・自動高さの確認項目

未実施。ブラウザー起動を伴うため、ユーザーが「全てのテストを実行」または「時間のかかるテストを実行」と明示した場合に実施する。

- [ ] 短文の訳文は20px、行高34pxで表示され、入力欄は1行分の高さになる。
- [ ] Tab／メニューから編集を開始し、Enter／Escape／完了で終了しても、同じtextareaが維持される。要素の座標・幅・高さと文字の画像を前後で比較し、キャレットと枠を除いて文字位置の差が0pxである。
- [ ] 長文の折り返し位置が編集中と編集後で一致し、最終行が欠けず、内部スクロールバーが出ない。
- [ ] 改行・連続改行・末尾改行・連続空白・長い英単語を含む訳文でも、全行が収まり、編集切り替えで移動しない。
- [ ] 空欄では入力案内が表示され、最低1行分の高さになる。狭い画面で案内が折り返しても欠けない。
- [ ] 入力・貼り付けで高さが増え、削除・全消去で必要な高さまで縮む。
- [ ] 画面幅を変更すると折り返しと高さが追従し、編集切り替えで位置が変わらない。
- [ ] 日本語IMEの変換中にEnterで編集が終了せず、確定後の終了と自動保存が従来どおり動作する。
- [ ] 編集開始時にフォーカスされ、編集中のTabは移動しない。終了後のTabで再編集でき、Undo／Redoで訳文と高さが戻る。
- [ ] 英文入力欄・一括入力・デバッグJSONの文字サイズと余白が変わらない。
