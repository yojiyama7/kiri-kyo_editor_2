# 自由標識入力のブラウザー確認

- [ ] NormalでToken、Group、T/D左右の各スロット上から `/` を押すと、現在のregion内に既存標識を初期値とした入力欄が表示され、入力へ合わせて幅と折り返しが更新される。
- [ ] 日本語をIME変換中のEnter/Escでは入力を継続し、変換後のEnterで前後空白を除去して確定する。Esc、`Ctrl+[`, 入力欄外のクリックでは文書を変更せず取り消す。
- [ ] `S`、`ad`、`O1`など既存表示を入力すると既存標識として矢印条件が働き、それ以外の文字列は表示だけを持つ自由標識になる。空白だけのEnterでは標識を削除する。
- [ ] 自由標識の確定・削除は各1回のUndo/Redoで復元され、入力途中の文字は保存・再読み込み・別の組への操作に漏れない。
- [ ] 空文、丸括弧、山括弧で `/` を押しても入力欄や編集履歴を作らず、Borderモードの `/` は引き続き疑似トークンを作成する。
