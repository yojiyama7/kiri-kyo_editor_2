# 境目モードのブラウザー確認（通常の検証では実行しない）

ブラウザー起動を伴うため、「全てのテストを実行」または「時間のかかるテストを実行」の明示要求時のみ実施する。

- [ ] normal のトークン・下線・T/D左右スロット上で `b`。対応トークンの左に縦線が現れ、スロットの選択強調が消え、BORDER と境目番号が表示される。
- [ ] `h/l`・左右矢印の連続入力で N+1 個の境目を移動。文頭・文末で止まり、`0/$` は折返しによらず文頭・文末へ移動する。
- [ ] `/` は疑似トークン作成の input を開く。確定・取消・IME・再編集・削除は `pseudo-browser-checks.md` に従う。
- [ ] `[` / `]` は角括弧、`(` / `)` はスロットなしの丸括弧を個別に挿入する。Backspace / Delete は隣の括弧または疑似トークンを削除し、通常トークンは残す。詳細は `brackets-browser-checks.md` と `pseudo-browser-checks.md` に従う。
- [ ] `j/k`・上下矢印・標識入力・`v/t/d/x/X/r/R/i/Tab/Enter/Space/b` では境目・文書が変わらない。トークン・下線・分割スロットのクリックも境目を変えない。
- [ ] Esc は右隣のトークンの左端側、文末では左隣の右端側の y=0 に復帰。基礎下線は閉じたまま、T/D は境目に近い側を選択する。
- [ ] 狭い画面・長い単語・長い標識・複数段や複数行にまたがる下線で、縦線が単語の上端から直下のスロット段（y=0）の下端まで伸び、次の段（y=1）以降にはみ出さない。同一行は隙間中央、折返しは次行頭、文末は最後のトークン直後。幅変更で境目番号は変わらない。
- [ ] 空の英文でも縦線は1本で、最初のグリッド段の上下端に収まり、移動は停止し、Esc 後は未選択の normal。
- [ ] 変更後に Undo → 境目モードで移動 → Esc → Redo と操作しても Redo が残る。BORDER 中の Undo/Redo は normal に戻り、復元されたカーソル位置を維持する。
- [ ] 未確定の標識を入力して `b` を押すと、その標識だけが確定・履歴化される。その後の境目移動やモード切替では履歴・保存文書が増減しない。
- [ ] BORDER から組切替・並べ替え・追加・削除・英文/訳文の編集ボタンへ移行しても境目状態が残らない。
- [ ] デバッグには BORDER と borderIndex/描画位置が出るが、保存データは既存の version 8 のままで境目状態を含まない。
