# 下線作成後のカーソルと履歴

- [ ] 初期サンプルの先頭で `v` → `l` → `Enter`。複合下線が1つ増え、新しい下線のSlot IDへ移動する（X=1、Y=1）。
- [ ] `vv` で先頭と「the student」の下線を個別選択し、未選択の「gave」へ戻って `Enter`。非連続下線を作成し、隙間ではなく新しい下線自身のスロットへ移動する。
- [ ] 初期サンプルの「the student」の基礎下線へ移動し、`k` → `v` → `l` → `Enter`。新しい基礎下線自身のスロットへ移動する（X=3、Y=0）。
- [ ] 上記3ケースとも、1回の `u` で作成直前の文書・カーソルを復元する。
- [ ] 上記3ケースとも、1回の `Ctrl+r` で作成直後の文書・カーソルを復元する（新しい下線のIDも一致）。
- [ ] ブラウザのエラーログなし。
