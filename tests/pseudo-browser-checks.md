# 疑似トークンのブラウザー確認（通常は実行しない）

実IME・ブラウザー起動を伴うため、「全てのテストを実行」または「時間のかかるテストを実行」の明示要求時のみ実施する。

- BORDER で `/` を押すと、境目の近くにネイティブの単一行 input が開き、自動フォーカスされる。文頭・途中・文末・空の英文を確認する。
- 日本語IMEで変換中に Enter/Esc を押しても疑似トークンは確定・取消されない。変換終了後の Enter で作成し、右境目で BORDER を続ける。Esc は元の境目へ戻る。
- 入力中の h/l/i/v/u やスラッシュは文字として入力できる。左右矢印・Backspace・選択・貼付けなどは通常の入力操作になる。Ctrl+n/p・Alt+j/k は組切替や並べ替えを起こさず、Ctrl+r はページを再読込しない。
- 前後・連続空白、空白だけの入力、日本語、記号、絵文字を1つの疑似トークンとして保持する。文字色は線・標識と同じで、確定後に専用の枠や背景は付かない。HTML風の文字もコードでなく文字として表示される。
- 疑似トークンのスロット、またはそのT/D分割の左右スロットに normal カーソルを置いて i で再編集する。Enter で文字だけが更新され、ID・標識・構造・元のスロット位置が保持される。
- 空文字で再編集を確定すると、その疑似トークンと関連する下線・上位構造・分割・矢印が削除される。他のトークンは残り、右隣（末尾なら左隣、全削除なら未選択）へ戻る。空白だけへの変更は削除されない。
- 下線の途中への挿入は下線に自動追加されず、下線がその部分を飛ばす。T/D分割済み下線の連続性を壊す境目は説明を表示して挿入開始を止める。
- 入力中に別の組、スロット、英文/訳文編集ボタン、デバッグ欄などをクリックして入力欄から離れると、ドラフトが取り消される。再編集を空文字にした状態でも、フォーカスを離すだけでは削除されない。Tabによるフォーカス移動も同様。
- 入力欄が日本語・空白・絵文字・IME変換中文字の実測幅に合わせて伸縮し、空文字でも1文字分の幅が残る。前後のトークン・下線・矢印がその場で移動・折り返し、縮めると元の配置に戻る。
- 表示領域より長い入力では幅を切り詰めず、独立した行に置かれて図全体を横スクロールできる。標識やT/Dラベルの方が広い場合は列幅を維持し、小さいinputは中央に表示される。
- 入力による折り返しや画面幅変更でも同じinput要素を維持し、フォーカス・文字選択・IME変換が途切れない。行をまたぐ配置更新やスクロールだけでは取消されない。
- 作成中は仮トークンとして場所を取り、再編集中は元の文字が二重表示されない。入力を全削除しても、Enterまで仮トークンが残る。Escやフォーカス喪失で元の配置に戻り、未確定文字・仮スロットは保存や履歴に入らない。
- 作成・更新・連鎖削除は各1回の Undo/Redo で戻せる。取消・空文字の新規作成・変更なしの再編集では履歴が増えず、Redoも残る。
- 英文全体の入力欄には実トークンのみが出る。無変更で終了すると疑似トークンも構造も残り、英文を変更すると警告文どおり疑似トークン・構造・標識がリセットされる。訳文は残る。
- 入力中のドラフトは保存JSONへ入らず、確定後に既存の自動保存へ反映される。再読込で実・疑似の区別と文字が戻り、旧データのkind未指定トークンは実トークンとして読める。
