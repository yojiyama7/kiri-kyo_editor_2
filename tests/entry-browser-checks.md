# 複数組のブラウザ確認

- [ ] 3組を表示し、追加した空の組で英文入力が開始される。英文・訳文を個別に編集できる。
- [ ] `Ctrl+n/p` で前後の組へ移動し、移動先のカーソルがX=0になる。選択中の移動で選択とモードを解除する。
- [ ] 英文入力中の `Ctrl+p` は組を移動せず、入力モードを維持する。
- [ ] `Alt+j` で組が入れ替わり、組IDとX=1のカーソルを維持する。Undo / Redoで順序を復元できる。
- [ ] 2組目で標識、T化、下線、矢印を編集しても1・3組目のデータは変化しない。
- [ ] スロットをクリックしてから `r` → 移動 → `Enter` で矢印を確定できる。フォーカスされたスロットボタンのクリック処理と競合しない。
- [ ] 非アクティブの組にカーソルの強調が残らない。
- [ ] 別の組からUndoすると対象の組へ戻る。組の削除をUndoすると組ID・全文・構造・標識・T化・矢印を復元する。
- [ ] 全組を削除しても空の1組を残す。連続した3回の削除をUndoすると元の文書を完全に復元する。
- [ ] 基礎下線の内部編集を開いたまま別の組へ移動し、その別の組の編集をUndoしても、元の組の構造が変化しない。
- [ ] 英文入力中に別の組の訳文編集をクリックすると英文を確定する。さらに別の組をクリックして訳文を確定し、Undoで訳文→英文の順に戻せる。
- [ ] 再読み込みで全組の順序・ID・構造・訳文を復元する（JSONのキー順は除いて比較）。
- [ ] 未保存の初回起動直後から、表示文書と一致するversion 8が自動保存される。
- [ ] ブラウザのエラーログなし。検証後に幅指定を解除し、検証タブと開発サーバーを終了した。

## 訳文入力中のキー操作

- [ ] 訳文入力中の `Tab` / `Shift+Tab` でフォーカス・選択位置・入力内容・入力モードが変わらない。
- [ ] 訳文入力中の `Ctrl+p/n` で前後の組へ移動し、訳文を確定して移動先のNormalモード・X=0に戻る。
- [ ] 先頭での `Ctrl+p`、末尾での `Ctrl+n` は訳文入力とフォーカスを維持する。
- [ ] 移動時に確定した訳文をUndo / Redoできる。変更せずに文を移動しても履歴を追加しない。
- [ ] 英文入力中の `Ctrl+p` は組を移動せず、入力モードを維持する。
- [ ] 再読み込み後に両方の訳文を復元する。ブラウザの警告・エラーログなし。
