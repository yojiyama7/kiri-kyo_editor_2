# 下線の標識幅と単語幅の分離

2026-09-03、検証用ローカルViteサーバー（5191）で確認。

- [x] `22. The man had meals at regular times every day.` を入力し、`every day.` に基礎下線を作成。
- [x] `ado` の設定前後で `every` は67.21875px、`day.` は54.578125px、両語間は10pxのまま。
- [x] 下線は標識なしで131.796875px、`ado` で150px。内部を中央に置き、左右の余白は各9.1015625px。
- [x] `at regular times` の複合下線、`regular → times` と `ad → had` の矢印を追加。隣接する下線に余分な重なりがない。
- [x] 390px幅では2行に折り返し、`ado` は150px、単語幅は不変。図の不要な横スクロールなし。下線と矢印の継続点、選択ハイライトを画面で確認。
- [x] 標識削除で下線が131.796875pxへ戻り、Undo/Redoで150pxへ復元。単語幅は不変。
- [x] 同じ下線のT分割では左右150pxずつ、分割元300px。折り返した最後の表示区間に配置され、内部の単語幅は不変。Undoで通常の下線へ復元。
- [ ] D分割の片側に `aux`、反対側に空または短い標識を設定し、両方の標識が枠内に収まる。D全体幅が元幅と左右必要幅の和の大きい方になり、単語Dでは単語がD全体の中央に見える。左右を入れ替えても同様。
- [ ] D分割の左右に異なるform、入力中の自由標識を表示し、幅変更・Undo/Redo・再読み込み後も切れや重なりがない。
- [x] ブラウザの警告・エラーログなし。
- [x] 通常幅へ戻すと1行で下線150px。検証用の追加データはUndoで取り消し、元の1組へ戻した。画面幅の指定も解除。
