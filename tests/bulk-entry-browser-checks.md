# 英文一括追加のブラウザ確認

- [ ] 各組に「英文を一括追加」が表示され、開いた組の番号と挿入位置をダイアログ内で確認できる。
- [ ] 開くと英文テキストエリアへフォーカスする。初期状態と空白・改行だけの入力は0件となり、追加ボタンが無効になる。
- [ ] CRLF・空行・タブ・連続空白を含む3行を追加すると、正規化した英文3組が順序どおり追加される。重複した英文も別の組として保持される。
- [ ] 追加した組の訳文・標識・下線・T化・矢印は空。既存のサンプルの構造と訳文は不変。
- [ ] 追加後は最初の新規組の先頭スロット（X=0、Y=0）がNormalで選択され、その組へフォーカスと表示位置が移る。スクリーンショットで確認。
- [ ] 中間の組から2行を追加すると直後に挿入され、後続の既存組の順序・ID・内容が保持される。
- [ ] 一括入力中のEnterは改行となる。Ctrl+n/p、Alt+j、uを入力しても背後の文書・選択組は変化しない（複数組でも確認）。
- [ ] キャンセル・Escで下書きが破棄され、元のボタンへフォーカスが戻る。再度開くと空欄になり、文書は変わらない。
- [ ] Tab / Shift+Tabはダイアログ内で循環する。空欄時は無効な追加ボタンを飛ばし、入力後は追加ボタンも含めて循環する。
- [ ] 1回のUndoで追加した全組を取り消し、追加前の選択組・カーソル・全文書を復元する。Redoでは同じID・順序・選択組を復元する。
- [ ] Undo後にダイアログを開いて入力・キャンセルしてもRedoが保持される。
- [ ] 単一組の英文入力中に一括追加を開くと英文を確定する。追加後の1回目のUndoは追加だけを戻し、2回目のUndoで英文編集を戻せる。
- [ ] 表示文書と保存状態JSONが一致し、再読み込み後も全6組の順序・ID・全文書を復元する。
- [ ] ダイアログの説明・入力欄・件数・ボタンの配置をスクリーンショットで確認。ブラウザの警告・エラーログなし。
