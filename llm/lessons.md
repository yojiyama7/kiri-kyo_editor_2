# 既知の注意点と知見

長期間役立つ注意点や、不具合の再発防止に必要な知見を、次の形式で記録する。

## 記録形式

### 対象または症状

- 原因: 確認済みの原因
- 対策: 実装時または検証時に守ること
- 関連: 関係する機能、ファイル、テスト

## 記録済みの知見

### Git上の変更を取り消す作業

- 原因: `git reset` はブランチ履歴を書き換えてコミットを履歴から取り除くため、取り消しの経緯が残らず、共同作業や後からの確認を難しくする。
- 対策: Undo・巻き戻し・特定コミットまで戻す依頼では `git reset` を使わない。原則として `git revert` で打ち消しコミットを作り、複雑な場合も差分を反転した新しいコミットとして履歴を維持する。
- 関連: Gitによる変更取り消し作業全般。

### Svelteテンプレートから呼ぶヘルパーの反応性

- 原因: テンプレート内で呼ぶヘルパーがコンポーネント状態を関数内から暗黙参照すると、Svelteがその状態をテンプレート式の依存として追跡せず、内部状態だけ更新されて表示が再描画されないことがある。
- 対策: 表示値を返すヘルパーには反応対象の状態を引数として明示的に渡し、テンプレート式から依存が見えるようにする。
- 関連: `src/KeybindingSettings.svelte` のキーバインド入力欄。

### 実時間を要するテスト

- 原因: 一部の検証は、実時間の待機、連続入力、またはブラウザー起動を必要とする。
- 対策: 通常は `npm test` のみを使い、ユーザーが明示した場合に限って `npm run test:all` または `npm run test:slow` を実行する。詳細は `AGENTS.md` を参照する。
- 関連: `tests/slow/`、`*.slow.test.mjs`、`tests/run-tests.mjs`

### モーダル内スクロールの背後への連鎖

- 原因: モーダル内のスクロール領域が端に達すると、ホイール操作がルートのスクロールへ連鎖し、背後のエディタが移動しうる。
- 対策: モーダル表示中は文書ルートとbodyのスクロールを固定し、モーダルと内部スクロール領域には `overscroll-behavior` を指定する。解除時は元のinline指定を復元し、後から設定された別のスクロール方針を上書きしない。
- 関連: `src/KeybindingSettings.svelte`、`src/documentScroll.ts`、`tests/keybindingSettings.test.mjs`
