# LLM長期記憶

このディレクトリは、セッションをまたいでエージェントが参照すべき、長期的に有効な情報を保存する。

## 読み分け

- プロジェクトの目的、技術構成、主要コマンドを確認する: `project.md`
- 採用済みの設計判断と、その理由を確認・記録する: `decisions.md`
- 既知の注意点、失敗しやすい点、再発防止策を確認・記録する: `lessons.md`

作業開始時には、上記から現在の作業に関係するファイルを少なくとも1つ選んで最後まで読む。関係する領域が複数なら、該当するファイルをすべて読む。

## 更新方針

- 将来の複数の作業で役立つ、確認済みの事実だけを残す。
- 設計判断には、判断内容だけでなく理由と影響範囲も記す。
- 不具合から得た知見には、症状、原因、再発防止策を簡潔に記す。
- コードや設定から容易に確認できる詳細を大量に複製しない。
- 一時的な作業状況、未確認の推測、個人情報、認証情報、秘密情報は記録しない。
- 情報が古くなった場合は追記だけで済ませず、既存記述を更新または削除する。
