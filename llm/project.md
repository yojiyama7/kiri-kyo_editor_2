# プロジェクト概要

## 基本情報

- パッケージ名: `kiri-kyo-editor-2`
- フロントエンド: Svelte 5、TypeScript、Vite
- モジュール形式: ESM

## 主要コマンド

- 開発サーバー: `npm run dev`
- 通常のテスト: `npm test`
- 型・Svelteチェック: `npm run check`
- プロダクションビルド: `npm run build`
- 遅いテストを含む全テスト: `npm run test:all`
- 遅いテストのみ: `npm run test:slow`

テストの実行範囲は、必ずルートの `AGENTS.md` にある「テスト実行方針」に従う。

## 主要資料

- 仕様: `SPEC.md`
- 未完了事項: `TODO.md`
- エージェント共通ルール: `AGENTS.md`
